# Arbeitsregeln für Codex

Vor jeder Aufgabe docs/MASTERPLAN.md, docs/tasks/P0_Auftragsplan.md und die relevanten Abschnitte aus docs/research/08_Technische_Architektur.md lesen. Nur den ausdrücklich freigegebenen Auftrag bearbeiten. Aktuell SF-003A; keine weiteren Aufgaben ohne Freigabe. Kleine Änderungen, pytest, deutsche Ergebnisdokumentation, lokale Commits; kein Push oder Release ohne Freigabe.

Storyentwicklung hat Vorrang. Fade In ist optional. Keine Überarchitektur, keine autonomen Agenten, keine Graphdatenbank in P0. Autorfreigabe vor Kanonänderungen; Varianten isolieren.

Öffentliches Repository: niemals private Skripte, unveröffentlichte Stoffe, persönliche Präferenzen, Projektdatenbanken, vollständige vertrauliche Forschungsberichte, Zugangsdaten oder API-Schlüssel committen. Nur synthetische Fixtures. Vor jedem Commit staged diff auf vertrauliche Inhalte prüfen; .gitignore ist lediglich zusätzlicher Schutz. Externe Datenübermittlung nur ausdrücklich freigegeben. Fehlende private Quellen melden, nicht erfinden.
